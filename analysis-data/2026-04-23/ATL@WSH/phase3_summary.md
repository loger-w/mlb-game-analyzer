## §整體判斷（方向性，非盤口）

- **勝方方向**：Formula Log5 與 Pythag 雙雙偏 **ATL**（約 55-56%），但 XGBoost 模型檔案未載入（`cross_validation = NO_ML_MODEL`）；D1 紀律下 ML 大概率 PASS。Ritchie 首登使模型輸入不可信也補強 PASS 傾向。
- **總分方向**：修正後總分 ~9.6-9.8，與 O/U line 9.45 差距 +0.15~0.35 run → 在噪音（SD 4.5）內，D2/D5 PASS 區間。
- **讓分方向**：ATL 形勢優（連勝 + 牛棚較佳），但 +1.15 受讓屬微幅讓；模型 Formula 差 ATL > WSH by 約 0.9 run，小於 1.15 → 若推國民受讓將邊緣取勝；ATL 讓分（−1.15）差距需 ≥ 1.5 才穩。
- **風險**：(1) Ritchie 首登上限/下限落差巨大；(2) 雙方牛棚早啟（Cavalli 過去 5 場 ~4 IP 平均）使中段失分變異大；(3) WSH BABIP 反彈可能給最近疲軟打線一記強心針。

**方向傾向摘要**：基本面偏 ATL，但三項差距皆小於信號閾值，盤口可能多數 PASS。最終推薦以 Phase 4 `predict.py --save` 為準。
